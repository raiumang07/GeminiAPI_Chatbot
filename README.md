
# 🌟 GeminiAPI_Chatbot

A sleek, responsive chatbot UI powered by Google's Gemini API — designed for seamless interactions with customizable themes and persistent chat history.

---

## 🧠 Features

- 🎨 **Responsive Design** – Looks great across devices
- 🌗 **Theme Toggle** – Switch easily between light and dark modes
- 🕒 **Chat History** – Conversations stored using local storage
- 📋 **Copy Responses** – Easily copy bot replies to clipboard
- 💡 **Smart Suggestions** – Quick prompts to spark conversation
